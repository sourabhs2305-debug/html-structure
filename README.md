# task
HTML Structure and Basic Server Interaction
Objective: Introduce the concept of server-side rendering and basic form
submissions.
Steps:
1.
Build a basic HTML page with a form to collect user input.
2.
Set up a simple Node.js server using Express.
3.
Create backend routes to handle form submissions.
4.
Use server-side rendering (like EJS) to dynamically display submitted data on
the page.

# following command should be run : 
# npm install
# node server.js

npm install will install all node module.
node server.js will run the project on specified port.
